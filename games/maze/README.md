# Mind Over Maze

Random maze generator and walker by Randy Ding (1983, revised 1992), ported to *ptcGraph*.

The program first asks, in the terminal, for the size of the cells (2 is hard, 95 is easy) and for the maximum length of the branches. Then it draws a maze, that you have to walk through from one side to the other.

## Keys

| Key | Action |
|---|---|
| Arrows or I, J, K, M | Walk through the maze |
| X | Give up and show the solution |

## Build

```
make
./maze
```
