# Sokoban

Sokoban game by Yevhen Yevsyuhov ([pascalSokoban](https://github.com/Yevs/pascalSokoban)), ported to *ptcGraph*.

You play as the yellow box. Your goal is to push all the white boxes onto the red plates. Once a box is placed on a plate, the plate becomes green. When all the boxes are placed, the level is won and you move on to the next one. The game has eight levels.

## Keys

| Key | Action |
|---|---|
| Arrows | Move, or choose in a menu |
| Enter | Validate a menu choice |
| Escape | Pause menu, or back from the help and about screens |

## Build

```
make
./sokoban
```
