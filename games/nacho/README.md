# Nacho Cabanes' examples

Two examples from the course *Introducción a la programación de juegos* by Nacho Cabanes, ported to *ptcGraph*. The texts of the games are in Spanish.

## Hangman

Guess the name of a Spanish city, letter by letter. After five wrong letters, the hangman is complete and the game is lost.

## Mini Snake

Drive the snake with the keys E (up), X (down), S (left) and D (right).

## Build

```
make hangman
make minisnake
```
