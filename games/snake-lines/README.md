# Snake

Simple snake game for *ptcGraph*.

Uses the [BASS](https://www.un4seen.com/) library for sound.

The snake and the apple are drawn as simple squares.

An improved version of the program, with graphics, is available on [Codeberg](https://codeberg.org/rchastain/snake-ptcgraph).

## Build

```
make
make start
```

To choose the language of the game:

```
make english
make french
```
