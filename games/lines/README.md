# Lines

The classical *Lines* game, written in Turbo Pascal by [Nane Petrosyan](https://github.com/nane-petrosyan/lines), ported to *ptcGraph*.

- 9x9 field
- select a ball then select an empty square to move
- 3 new random balls generated after every turn
- the goal is to keep the field empty as long as possible

## Build

```
make
./lines
```
