# Snake

Simple snake game by Markus Mangold, published on [Pascal Game Development](https://www.pascalgamedevelopment.com/showthread.php?32638-Another-simple-snake-game-(no-OOP)), ported to *ptcGraph*.

Eat the apples before the countdown ends: after ten seconds, the apple moves and you lose three points. The snake gets faster after each apple. The ten best scores are saved in `snakehigh.dat`.

## Keys

| Key | Action |
|---|---|
| Arrows | Move the snake |
| P | Pause |
| Escape | End the game |

## Build

```
make
./snakegame
```
