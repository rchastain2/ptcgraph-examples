## Other files

- `gmodeinfo.pas`: lists the available graphic modes.
- `keywords.txt`: the identifiers of *ptcGraph* and *ptcCrt*, and the color names of [colornames](../colornames), one per line. It can be used to give identifiers their usual case in a source file.
